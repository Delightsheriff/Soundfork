# Soundfork

Per-app audio output routing for macOS, from a dynamic-island panel in the menu bar.

```
🎵 Spotify  → 🔵 JBL Flip 6
🌐 Chrome   → 💻 MacBook Speakers
💬 Discord  → 🎧 AirPods
```

- `docs/ARCHITECTURE.md`: tech stack, engine design, UI design
- `docs/PLAN.md`: phases, acceptance criteria, who does what
- `docs/DECISIONS.md`: why things are the way they are
- `prompts/`: handoff prompts for builder agents, one per phase
